# Cabinova Kraft

Wholesale manufacturer of custom cabinet components — doors, drawer fronts, drawer boxes, Linea ready-to-assemble cabinet boxes, molding, and hardware. Built as a complete trade website in the same category as a professional mill catalog: account application, online quoting, product library, gallery, and shop education.

**Trade only.** The site does not sell to homeowners. A homeowners page and contact form route consumers to a cabinet shop.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:43180](http://localhost:43180).

```bash
npm run build
npm start
```

## What is included

- Product catalog (Linea RTA, doors, drawer boxes, molding, accessories, hardware, specialty)
- Door styles with sizing and list pricing
- Materials, finishes, and twelve design styles
- Project gallery with style filters
- Learn library and mill blog
- Locations, careers, testimonials, environmental notes, downloads
- Multi-step **Become a customer** application
- **KraftDesk** quote builder (doors, boxes, RTA) stored in the browser
- Demo login: `demo@cabinovakraft.com` / `demo1234`

Pricing on this preview is published list for demonstration. A production plant would attach real multipliers, mill calendars, and ERP after account approval.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, and shadcn/ui.
